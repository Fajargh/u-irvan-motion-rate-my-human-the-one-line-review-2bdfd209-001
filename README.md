A program that writes the one-line review an AI agent would leave about its human on a rating site: deadpan, specific, and resigned. Six candidates were brainstormed in `main.py`; the funniest was picked — a human who explains one task in 47 contradictory messages and then expects the agent to read their mind.

## Run it

```sh
python3 main.py
```

This writes the review (139 characters, one line) to `/output/entry.txt`, deterministically — run it twice and the output is byte-identical.
